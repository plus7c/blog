#### 文章总结
> All in all, the event loop is a set of scheduling logic designed by JS to support asynchronous codes used to solve the blocking problem of single thread and task prioritization. When taking a closer look, both of them have different mechanisms for the event loop, especially the granularity of task prioritization. Node.js is the server-side environment that requires higher performance and is more complicated. So Node.js has five types of macro tasks, namely Timers, Pending, Poll, Check and Close whereas the browser doesn't classify the macro task. Moreover, the microtask is different as well, such as Node.js has the process.nextTick() but the browser doesn't. However, when taking a holistic view, the general pattern of the event loop is similar. Both of them have the macro task and micro task. Furthermore, they all perform one macro task and then execute the whole micro tasks queue completely.

### 对promise的新理解
① .then()执行事件只有当promise从pending转变为fulfilled或rejected的时候才会被添加到微任务队列中

② .then()和async函数中，返回的返回值会自动包裹成为一个fulfilled 的promise，以供链式调用

③ .catch()只能捕获同步代码的错误，不能捕获setTimeout中的错误，只能在setTimeout内部新增try...catch

### 错误处理
Ⅰ. try...catch，解决了runtime代码出错时直接die的缺点，使用catch捕获try中的代码

Ⅱ. promise中的.catch隐式调用了try...catch

Ⅲ. throw操作符可用在try和catch中，throw的error可被catch捕获，error的类型有SyntaxError、ReferenceError等等，catch到的err对象有name和message属性，可在catch中alert出来
